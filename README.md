# vet-management
Veterinary Clinic Management System built with Java and Spring Boot

#proje
Proje veteriner klinik yönetim sistemidir. İçerisinde randevu sistemi, hayvan bilgileri, laboratuvar sonuçları gibi veteriner için önemli olan bilgileri tek bir panelden kontrol edilmesini amaçlamaktadır.

#Technologies
-Spring Boot/ Java
-Maven
-PostgreSQL
