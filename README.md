# vet-management
Veterinary Clinic Management System built with Java and Spring Boot

## Proje
Proje veteriner klinik yönetim sistemidir. İçerisinde randevu sistemi, hayvan bilgileri, laboratuvar sonuçları gibi veteriner için önemli olan bilgileri tek bir panelden kontrol edilmesini amaçlamaktadır.

## Technologies
- Spring Boot/ Java
- Maven
- PostgreSQL

## Planned Features

- User authentication and role-based authorization
- Pet owner and animal management
- Appointment scheduling and management
- Vaccination tracking
- Medical examination records
- Prescription and medication management
- Laboratory test management
- Medical imaging and DICOM integration
- Email notifications and reminders
- PDF medical report generation
